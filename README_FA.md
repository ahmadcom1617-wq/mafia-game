# بازی مافیای آنلاین — نسخه مستقل مرورگر

این نسخه دیگر به تلگرام، ربات تلگرام، BotFather یا Telegram Web App وابسته نیست.

## اجرا

1. Node.js نسخه 18 یا بالاتر نصب باشد.
2. در پوشه پروژه اجرا کنید: `npm install`
3. سپس اجرا کنید: `npm start`
4. مرورگر را باز کنید و وارد `http://localhost:10000` شوید.

## انتشار روی هاست

پوشه‌های `public` و فایل‌های `server.js` و `package.json` را در ریشه پروژه GitHub قرار دهید. در سرویس میزبانی، دستور اجرا `npm start` باشد. سرویس باید پورت `process.env.PORT` را پشتیبانی کند؛ برنامه روی `0.0.0.0` گوش می‌دهد.

پس از انتشار، لینک سایت را برای دوستان بفرستید. هر بازیکن با مرورگر گوشی یا کامپیوتر وارد می‌شود، نام مستعار می‌زند، اتاق می‌سازد یا با کد وارد می‌شود.

## امکانات فعلی آزمایشی

- ساخت اتاق و ورود با کد
- پشتیبانی از حداکثر ۲۰ بازیکن در هر اتاق
- نقش‌های پایه، شب و روز، رأی‌گیری و چت روز
- ویس‌چت آزمایشی WebRTC؛ دسترسی میکروفون و HTTPS لازم است

## محدودیت‌های مهم

- این نسخه MVP است، نه بازی نهایی حرفه‌ای.
- اتاق‌ها در حافظه سرور هستند و با ری‌استارت سرور پاک می‌شوند.
- برای بعضی شبکه‌ها ویس‌چت به TURN server نیاز دارد؛ STUN عمومی تضمین اتصال در همه شبکه‌ها نیست.
- احراز هویت و ذخیره‌سازی دائمی بازیکنان پیاده‌سازی نشده است؛ فعلاً نام مستعار کافی است.
- قوانین نقش‌ها ساده‌سازی شده‌اند و باید پیش از انتشار عمومی کامل و تست شوند.
