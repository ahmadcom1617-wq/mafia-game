# بازی مافیای تلگرام

این پروژه شامل صفحه گرافیکی بازی و ربات تلگرام است. ربات با دستورهای `/start` و `/help` کار می‌کند و دکمه باز کردن بازی را می‌فرستد.

## نکته امنیتی مهم
توکنی که قبلاً در چت فرستاده شده را استفاده نکنید. در BotFather دستور `/revoke` را اجرا کنید و توکن تازه بگیرید. توکن فقط باید در متغیر محیطی `BOT_TOKEN` روی هاست وارد شود؛ آن را در کد یا چت عمومی قرار ندهید.

## نیازمندی‌ها
- Node.js نسخه 20 یا بالاتر
- یک آدرس عمومی HTTPS برای صفحه بازی
- متغیرهای محیطی مطابق `.env.example`

## راه‌اندازی
1. فایل‌ها را روی یک سرویس میزبانی Node.js آپلود کنید.
2. متغیرهای `BOT_TOKEN`، `WEBAPP_URL` و `REQUIRE_TELEGRAM_AUTH=true` را تنظیم کنید.
3. دستور `npm install` را اجرا کنید.
4. سرویس وب را با `npm start` اجرا کنید.
5. یک سرویس Worker/Background جداگانه با همان فایل‌ها و دستور `npm run bot` اجرا کنید.
6. در BotFather، دامنه HTTPS سایت را برای Web App تنظیم کنید (اگر تلگرام درخواست کرد).
7. در تلگرام ربات را باز کنید و `/start` بفرستید.

`WEBAPP_URL` باید دقیقاً آدرس عمومی HTTPS صفحه بازی باشد، مثلاً `https://example.com`.

## تست محلی
صفحه بازی روی `http://localhost:3000` اجرا می‌شود، اما Web App تلگرام برای استفاده واقعی به HTTPS عمومی نیاز دارد. برای تست ربات نیز `WEBAPP_URL` باید HTTPS باشد.

## محدودیت‌های نسخه اولیه
- اتاق‌ها در حافظه هستند؛ با ری‌استارت سرور پاک می‌شوند.
- اگر کاربر اتصالش را قطع کند از اتاق حذف می‌شود؛ بازیابی اتصال هنوز پیاده‌سازی نشده.
- ذخیره‌سازی دائمی، پنل مدیریت، پرداخت و مقیاس‌پذیری چندسروری وجود ندارد.
- این نسخه برای تست گروه کوچک است، نه استفاده پرترافیک.
