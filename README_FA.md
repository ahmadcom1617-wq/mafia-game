# بازی مافیای تلگرام — نسخه یکپارچه آزمایشی

## فایل‌ها
- `server.js`: سرور Express و Socket.IO با پورت سازگار Render (`process.env.PORT` و `0.0.0.0`)
- `bot.js`: ربات تلگرام با دکمه Web App
- `public/index.html`: رابط فارسی، اتاق‌ها، نقش‌ها، چت و ویس WebRTC
- `start.js`: اجرای وب‌سرور و ربات در یک سرویس

## تنظیم Render
- Build Command: `npm install`
- Start Command: `npm start`
- Environment:
  - `BOT_TOKEN` = توکن ربات (توکن افشاشده قبلی را باطل کنید و توکن جدید بگذارید)
  - `WEBAPP_URL` = `https://YOUR-SERVICE.onrender.com`

سپس Deploy latest commit.

## اتصال Telegram
در BotFather، از تنظیمات Mini App یا منوی ربات، آدرس HTTPS بالا را به‌عنوان Web App ثبت کنید. دکمه `/start` نیز همین URL را نمایش می‌دهد.

## محدودیت‌های مهم این نسخه
- این نسخه یک پایه قابل اجرا و آزمایشی است، نه محصول نهاییِ امن و کامل.
- اتاق‌ها در حافظه هستند؛ با ری‌استارت Render از بین می‌روند.
- برای تست حداقل ۴ بازیکن لازم است؛ ظرفیت ۲۰ نفر است.
- ویس چت از WebRTC mesh و STUN عمومی استفاده می‌کند. در بعضی شبکه‌ها/اپراتورها بدون TURN کار نمی‌کند؛ برای پایداری باید TURN server و اعتبارنامه آن پیکربندی شود. کنترل نقش‌محور میکروفون و اتاق‌های جداگانه هنوز کامل نیست.
- نقش‌ها و گردش بازی در حد MVP پیاده شده‌اند؛ برخی نقش‌های تخصصی، وصیت، دفاعیه، رأی مخفی پیشرفته، ذخیره دائمی، ضدتقلب و پنل گرداننده در این نسخه وجود ندارند.
- احراز هویت Telegram `initData` سمت سرور در این بسته پیاده‌سازی نشده است؛ برای انتشار عمومی باید اضافه شود.
